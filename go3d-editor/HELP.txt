================================================================
 go3d-editor 3D 建模编辑器 —— 帮助手册（分模块说明）
================================================================

界面布局（SolidWorks 风格）
----------------------------------------------------------------
  ┌──────────────────────────────────────────────────────────┐
  │ 工具栏三行：                                           │
  │ 行1 基本体 ＋立方体/球体/圆柱/圆锥/圆环/平面 新建 保存 载入 │
  │  行2 编辑模式(建模/草图/骨骼/动画) 变换(G/R/S) 模式专属 │
  │  行3 视图(顶/前/右/等轴) 透视 网格 取景 删除 复制 显隐 │
  │      吸附[F] 类型 帮助[F1] 插件 主题                   │
  ├──────────┬──────────────────────────────┬──────────────┤
  │ 模型树    │        3D 视口               │ 属性面板      │
  │ (特征图标)│  (网格+坐标轴+Gizmo)          │ (右侧)       │
  ├──────────┴──────────────────────────────┴──────────────┤
  │ 状态栏：消息 / 吸附状态 / 特征数 / FPS / 相机坐标       │
  └────────────────────────────────────────────────────────┘

Tab 在四个编辑模式间循环：建模 → 草图 → 骨骼 → 动画
主题：工具栏 [主题] 按钮或 T 键，在 暗色/白色 间切换（持久化保存）


模块一：建模（基本体 + 变换 + 布尔 + 导入导出）
----------------------------------------------------------------
 添加基本体：工具栏行1  ＋立方体 ＋球体 ＋圆柱 ＋圆锥 ＋圆环 ＋平面
 选中对象：  左键点击视口中的物体，或点击左侧模型树节点
 变换模式：  G 移动 / R 旋转 / S 缩放（工具栏按钮同）
    - 左键拖拽 Gizmo 轴（红X 绿Y 蓝Z）沿轴变换
    - 缩放模式下拖拽中心圆 = 等比缩放
    - 属性面板可直接输入 位置/旋转(度)/缩放 数值，回车生效
 布尔运算（CAD 风格：先选 B 再选 A）：
    - 先点选一个对象（B，模型树弱高亮）
    - 再点选另一个对象（A，模型树强高亮）
    - 点 并集 / 差集A-B / 交集（两个都选中时按钮高亮可点）
    - 结果自动加入模型树，名字如 差集_xxx
 导入/导出： OBJ↓ 导入  OBJ↑ 导出选中  STL↓ 导入  GLB↓ 导入  GLB↑ 导出
    （OBJ/GLB 与 Blender 互通；STL 二进制/ASCII 自动识别）


模块二：草图（折线 / 矩形 / 圆 → 拉伸成实体）
----------------------------------------------------------------
 进入草图模式（Tab 或点击"草图"），选择基准面：前视 XY / 顶视 XZ / 右视 YZ
 工具：
   [折线] 视口逐点点击，Enter 闭合
   [矩形] 点第一角 → 点对角（实时预览）
   [圆]   点圆心 → 点半径（实时预览）
   [闭合] 手动闭合折线    [清除] 清空当前草图
 完成后点击 [拉伸] 生成实体（默认拉伸 1.0 深度）
 提示：网格吸附开启时（F 开，网格类型勾选）草图点自动对齐 0.5 网格


模块三：骨骼绑定 + 白模动画
----------------------------------------------------------------
 骨骼：
   - 选中对象 → 点击 [＋骨骼] 添加骨骼（选中骨骼后添加的是其子骨骼）
   - 视口点击绿色关节点选中骨骼，Gizmo 编辑骨骼位置/旋转
   - [绑定权重] 自动计算顶点权重（最近 4 骨骼距离倒数加权）
   - [重置姿势] 恢复绑定姿势
 动画：
   - 选中骨骼 → [＋关键帧] 在当前位置记录一帧
   - 左右方向键推进时间轴，[播放/暂停] [停止] [清动画]
   - 播放时骨骼动画驱动网格蒙皮变形


模块四：保存 / 载入 / 新建 / 一键清除
----------------------------------------------------------------
Ctrl+S 或点击 [保存]：
   - 弹出保存对话框，输入 文件名/路径（相对 home 目录）
     例：hermes11/go3d-toolchain/go3d-editor/scene.json
     也支持绝对路径（以 / 开头）：/data/data/com.termux/files/home/xxx.json
   - 回车或点 [保存] 执行；Esc 或点外部取消
   - 对话框显示解析后的绝对路径预览
Ctrl+O 或点击 [载入]：从默认路径载入 scene.json
Ctrl+N 或点击 [新建]：新建文档（清空场景 + 重置全部编辑状态）
[清除] 按钮（工具栏行3，删除旁）：一键清空场景全部对象


模块五：吸附（CAD OSNAP 风格）
----------------------------------------------------------------
 F 键 或 [吸附] 按钮：吸附总开关
 [类型] 按钮（或 Alt+F）打开吸附设置面板，可多选：
   [网格]   移动/草图点对齐 0.5 网格
   [端点]   移动到其他物体顶点
   [中点]   移动到其他物体边的中点
   [圆心]   移动到其他物体中心
 优先级：端点 > 中点 > 圆心 > 网格
 状态栏实时显示当前吸附类型组合


模块六：插件（扩展点，为未来发展预留）
----------------------------------------------------------------
 [插件] 按钮打开插件面板，列出已注册插件及动作。
 插件接口：app.Plugin（Name() + Actions()），main.go 里
 app.RegisterPlugin(...) 注册（纯 Go 无 cgo，编译时注册）。
 内置示例：统计插件（场景统计：对象/三角形/顶点数）。
 扩展方向：导入器/导出器、建模命令、渲染增强、脚本执行等。


视图与通用操作
----------------------------------------------------------------
 中键拖拽  轨道旋转视图     右键拖拽  平移视图
 滚轮      缩放视图         左键      选择 / 拖拽 Gizmo / 草图绘制
 行3 按钮：顶视 前视 右视 等轴 | 透视/正交 网格 取景 删除 复制 显隐


快捷键总表
----------------------------------------------------------------
 单键（常用）：
   G/R/S      移动/旋转/缩放模式
   1/2/3/7    前视/等轴测/右视/顶视
   P          透视/正交切换
   空格       网格显示开关
   F          吸附开关
   T          主题切换（暗色/白色）
   Del        删除选中特征      C    复制选中特征
   H          显示/隐藏         F1   帮助（新会话）
   Tab        切换编辑模式
   A          骨骼模式添加骨骼
   Enter      草图闭合 / 确认输入    Esc  取消 / 取消选择
   ←→         动画模式推进时间轴
 组合键（高级操作）：
   Ctrl+S     保存（询问文件名/位置）
   Ctrl+O     载入
   Ctrl+N     新建文档
   Ctrl+E     导出选中 OBJ
   Ctrl+I     导入 OBJ
   Ctrl+D     复制（同 C）
   Shift+F    选中对象取景
   Alt+F      吸附类型面板
   Alt+T      主题切换（同 T）
   Alt+B      添加骨骼（同 A）
   Alt+W      绑定权重
   Alt+K      添加关键帧
   Alt+X      清除草图
   Alt+1/2/3  草图平面：前视/顶视/右视


文件格式
----------------------------------------------------------------
 scene.json  场景（含自定义网格/骨骼/动画），可完整恢复编辑
 OBJ         与主流建模软件互通（顶点+三角面）
 STL         二进制/ASCII 自动识别（3D 打印通用格式）
 GLB/GLTF    glTF 2.0，与 Blender 直接互通
