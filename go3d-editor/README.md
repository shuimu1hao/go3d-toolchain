# go3d-editor — 3D 建模编辑器（SolidWorks 风格界面 + Blender 风格视口）

基于 go3d 软渲染引擎的桌面 3D 建模编辑器，纯 Go 零 cgo。
界面参照 SolidWorks：顶部工具栏 / 左侧模型树 / 中间 3D 视口 / 右侧属性面板 / 底部状态栏。
建模逻辑参照 SolidWorks 特征树 + Blender 视口操作（轨道相机、Gizmo 变换、正交/透视）。

## 功能（两大模块 + 工程能力）

### 模块一：建模
- 6 种基本体：立方体/球体/圆柱/圆锥/圆环/平面
- **草图绘制**（SolidWorks 核心工作流）：折线/矩形/圆工具、前视/顶视/右视基准面、
  视口点击绘制、Enter 闭合、**拉伸成实体**；矩形/圆带**实时预览**（CAD 风格）
- **布尔运算**：并集/差集/交集（CSG：互裁剪 + 补面 + 包围盒剔除，立方体-球体 11ms/588 面）
  **CAD 选择逻辑：先选 B 再选 A**（A=当前选中、B=上次选中，模型树双高亮区分）
- 变换：Gizmo 拖拽（移动/旋转/缩放）+ 属性面板数值输入
- **吸附（CAD OSNAP 风格）**：F 键开关，类型面板多选（网格/端点/中点/圆心），
  优先级 端点>中点>圆心>网格；草图点自动对齐网格
- 特征树：添加/删除/复制/重命名/可见性（SolidWorks 风格类型图标）
- **OBJ 导入/导出**（主流建模软件互通）
- **STL 导入**（二进制/ASCII 自动识别，3D 打印/网格交换通用格式）
- **GLTF/GLB 导入 + GLB 导出**（glTF 2.0：JSON accessor/bufferView/buffer 解析，
  内联 base64/外部 buffer/GLB 二进制 chunk 全支持，与 Blender 直接互通）
  （工具栏第一行 OBJ↓/OBJ↑/STL↓/GLB↓/GLB↑ 按钮，建模模式显示）

### 模块二：骨骼绑定 + 白模动画
- **骨骼系统**：层级树（根/子骨骼）、添加/删除/重选、Gizmo 编辑局部变换、绿色骨线可视化
- **顶点绑定**：自动权重（最近 4 骨骼距离倒数加权）、绑定姿势管理
- **白模动画**：关键帧（每骨骼 位置/旋转）、时间轴（左右方向键推进）、播放/暂停/停止/循环、
  骨骼动画驱动网格蒙皮变形

### 工程能力
- **保存对话框**：Ctrl+S 询问保存位置和文件名（相对 home 或绝对路径），目录自动创建
- **主题切换**：暗色/白色两套配色（工具栏按钮或 T 键），持久化到 ~/.config/go3d-editor/config.json；
  暗底白字/白底黑字，对比度清晰
- **帮助系统**：F1/帮助按钮打开新终端会话（xfce4-terminal），分模块详细说明（HELP.txt）
- **插件扩展点**：app.Plugin 接口 + 注册表 + 插件面板（为未来深入发展预留）；
  内置示例：统计插件
- **UI 全覆盖**：所有功能均有工具栏按钮，快捷键作为补充（高级操作用 Ctrl/Alt 组合键）
- **三行工具栏**（SolidWorks 风格）：行1 基本体/格式/保存载入、行2 模式/变换/模式专属、
  行3 全局操作（视图/透视/网格/取景/删除/复制/显隐/吸附/帮助/插件/主题）

## 启动

```bash
bash build.sh
./bin/go3d-editor                # 1100x680 窗口
./bin/go3d-editor --res 1280x720
./bin/go3d-editor --load scene.json   # 启动加载场景（加载失败仅警告，不退出）
```

## 操作

| 操作 | 说明 |
|---|---|
| Tab | 切换编辑模式（建模→草图→骨骼→动画） |
| 左键点击 | 视口拾取选中 / 树节点选中 / 属性字段聚焦 |
| 左键拖拽 Gizmo | 移动/旋转/缩放选中物体或骨骼（红X 绿Y 蓝Z） |
| 中键拖拽 | 轨道旋转视图 |
| 右键拖拽 | 平移视图（Pan） |
| 滚轮 | 缩放视图 |
| G / R / S | 切换 移动/旋转/缩放 模式（工具栏按钮同） |
| 1 / 2 / 3 / 7 | 前视 / 等轴测 / 右视 / 顶视（工具栏按钮同） |
| P | 透视/正交切换（工具栏按钮同） |
| F | 选中物体取景 → 已改为：**F=吸附开关**，取景=Shift+F |
| 空格 | 网格开关（工具栏按钮同） |
| Del | 删除选中特征（工具栏按钮同） |
| C / Ctrl+D | 复制选中特征（工具栏按钮同） |
| H | 显示/隐藏（工具栏按钮同） |
| F1 / 帮助按钮 | 打开帮助（新终端会话，分模块说明） |
| T / Alt+T | 主题切换（暗色/白色） |
| Ctrl+S / Ctrl+O / Ctrl+N | 保存（对话框）/ 载入 / 新建 |
| Ctrl+E / Ctrl+I | 导出选中 OBJ / 导入 OBJ |
| Alt+F | 吸附类型面板 |
| Alt+B / Alt+W / Alt+K / Alt+X | 添加骨骼 / 绑定权重 / 关键帧 / 清除草图 |
| Alt+1/2/3 | 草图平面：前视/顶视/右视 |
| 双击树节点 | 重命名 |
| 草图模式 | 折线/矩形/圆 工具 → 视口点击（实时预览）→ Enter 闭合 → 拉伸 |
| 骨骼模式 | A/Alt+B 加骨骼、点击选骨骼、Gizmo 编辑、Alt+W 绑定权重 |
| 动画模式 | Alt+K 关键帧、左右方向键推进时间、播放/暂停/停止 |

│   ├── plugin.go   插件接口 + 注册表 + 内置示例

## 文件格式

- 场景：JSON（含自定义网格、骨骼层级、动画轨道；权重加载时按绑定姿势重算）
- 模型：OBJ 导入/导出（与 Blender/主流建模软件互通）
- 配置：~/.config/go3d-editor/config.json（主题等持久化）
