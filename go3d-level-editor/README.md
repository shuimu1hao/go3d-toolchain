# go3d-level-editor — 关卡编辑器（模型/动画 → 场景 → 游戏）

go3d 游戏制作工具链的第二大模块：把建模编辑器产出的模型/动画组装成可玩的关卡。
纯 Go 零 cgo，基于 go3d 软渲染引擎 + go2dgame X11 + go3d-editor 核心模型。

## 功能

### 场景搭建
- **载入建模 JSON**：一键导入建模编辑器场景，每个对象成为模型资源
  （含自定义网格/骨骼/动画/顶点权重，走 go3deditor/app 共享核心）
- **实例化**：模型资源可重复放置为实例（独立变换 + 独立骨骼副本，动画互不干扰）
- **贴图素材**：载入 PNG/JPEG → 素材列表 → 点击素材添加为**精灵公告板**（2D 叠加渲染）
- 实例操作：场景树选中 / 视口拾取 / Gizmo 移动/旋转/缩放（G/R/S）/ 删除

### 渲染动画
- 实例自动播放其骨骼动画（建模编辑器录制的关键帧动画）
- 播放/暂停/重置 per 实例

### 按键设置 + 运行模式
- 默认映射：WASD 移动 / 空格跳跃 / Shift 加速（InputMap，可扩展改键）
- **运行模式（F5/按钮）**：玩家实例（属性面板"设为玩家"）受 WASD 控制，
  相机跟随，简化物理（重力/落地/跳跃），Esc 返回编辑
- 关卡 JSON 保存/载入（Ctrl+S/Ctrl+O 或按钮）

## 操作

| 操作 | 说明 |
|---|---|
| 载入建模JSON | 导入建模编辑器 scene.json（模型资源） |
| 载入素材图 | 加载 ~/hermes11/assets/ 下 PNG/JPG |
| 点资源名 | 添加模型实例（工具栏 ＋按钮） |
| 点素材名 | 添加精灵实例 |
| 场景树点击 | 选中实例 |
| G/R/S | 移动/旋转/缩放模式 |
| F5 / ▶运行 | 进入运行模式 |
| WASD/空格/Shift | 运行模式移动/跳跃/加速 |
| Esc | 返回编辑模式 |
| Ctrl+S / Ctrl+O | 保存/载入关卡 |

## 架构

```
go3d-level-editor/
├── app/
│   ├── level.go      Level 模型：ModelRes（资源）/Instance（实例，独立骨骼）/Sprite
│   ├── editor.go     主状态：布局/输入分发/命令/编辑+运行双模式
│   ├── viewport.go   视口渲染（go3d 软渲染 + 网格 + gizmo + 精灵公告板 + 拾取）
│   ├── play.go       运行模式：玩家控制 + 简化物理（重力/跳跃/落地）
│   ├── panels.go     面板：工具栏/资源列表/场景树/属性/状态栏/帮助
│   ├── inputmap.go   按键映射（动作 → 键）
│   ├── texture.go    PNG/JPEG 精灵加载与绘制（最近邻缩放 + alpha 混合）
│   └── io.go         关卡 JSON 保存/加载（模型引用 + 素材路径 + 实例）
└── cmd/go3d-level-editor/  入口
```

依赖：go3d（软渲染）、go2dgame（X11 窗口/输入/画布）、go3deditor/app（文档/骨骼/动画核心，
新增 LoadDocumentFile 导出复用）。

## 文件格式

- 关卡：JSON（模型资源引用建模文件+索引、素材路径、实例变换/玩家/精灵标记）
- 模型：建模编辑器 JSON（含骨骼/动画/自定义网格）
